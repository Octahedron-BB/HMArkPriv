## 🧭 阅读建议

- **我是普通用户 / 极客**：
  直接阅读根目录 [README.md](../README.md)，配合 [HarmonyOS-Shell-指令全集.md](HarmonyOS-Shell-指令全集.md) 在 App 终端或快捷面板中畅玩特权指令。
- **我想让自己的 App 具备 Shell 特权**：
  直接阅读 [跨应用调用协议.md](跨应用调用协议.md)，将 `arkui_app/sdk/HmprivClient.ets` 引入您的项目即可秒级接入。
- **我想了解原理或贡献代码**：
  先读 [ARCHITECTURE.md](ARCHITECTURE.md) 理解底层权限隔离，再读 [HMArkPriv-App-技术方案.md](HMArkPriv-App-技术方案.md) 理解 App 结构。
